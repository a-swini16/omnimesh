# Code of Conduct

OmniMesh follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and patient, especially with beginners and people whose first language isn't English. Critique code, not people. Harassment, insults and personal attacks aren't tolerated anywhere in the project.

Report unacceptable behavior privately to the maintainers through the contact listed on the repository owner's GitHub profile. Every report is reviewed, and the reporter's privacy is respected.
