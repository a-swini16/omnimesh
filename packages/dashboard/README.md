# OmniMesh dashboard

The live dashboard is served by the router itself, so there is nothing separate to host:

```
https://<your-router-domain>/_omnimesh/dashboard
```

Sign in with the router's status token (`OMNIMESH_STATUS_TOKEN`, generated by `omnimesh init` into `.env`; on Cloudflare set it with `npx wrangler secret put OMNIMESH_STATUS_TOKEN`). Without a token configured, the page and the status API return 404.

It shows, refreshed every 3 seconds:

- requests, success rate, failovers and p50/p95/p99 latency
- every pool and node: serving, standby, down (with the reason) or quota reached
- free-tier quota bars, with warnings at 80% and the automatic switch at 95%
- a timeline of node failures, recoveries, failovers, quota switches and outages

The source is `packages/router/src/dashboard.ts`; the data comes from `GET /_omnimesh/status`.
On Cloudflare, counters belong to the router instance that answered (each isolate counts on its own); node health is shared through KV.
