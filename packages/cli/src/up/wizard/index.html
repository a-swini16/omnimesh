Host your backend on multiple clouds

Give OmniMesh your GitHub repo. It deploys it on every cloud you connect, puts one URL in front, and switches clouds automatically if one goes down.

Open the link from your terminal.

For your safety this page only works from the exact link omnimesh up printed (it contains a one-time key).

1

Your backend

The repo must be public, and your app must listen on the PORT environment variable (for example app.listen(process.env.PORT)). OmniMesh detects Node.js, Python and Docker by itself.

Your app's own environment variables, set on every cloud. Saved only on this computer (.omnimesh/).

A service is another part of your app on its own route, for example /auth, from its own repo or a folder of this one. It gets its own servers; your visitors still use one URL. Each service receives the full path (for example /auth/login).

Connect your clouds

all free

Create a free account on each one and paste an API token. Connect at least two hosting clouds so your app stays up when one fails.

More servers on Render share the work. Render gives your workspace 750 free hours a month, so only one Render server is kept awake; the others sleep when idle and wake on the next visit.

4

Keep it running

  1. Open GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your backend repo.
  3. Permissions: Contents, Workflows and Secrets, each "Read and write".
  4. Generate it, copy the token and paste it here.
