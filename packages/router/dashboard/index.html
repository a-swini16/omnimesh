Sign in to your OmniMesh dashboard

This page is for the owner of this app. Sign in once; this browser then remembers you.

Where is my sign-in key?
  1. Easiest: on the computer you deployed from, open a terminal in your deployment folder (the one with the .env file) and run omnimesh open. The dashboard opens already signed in.
  2. Or open the .env file in that folder and copy the value of OMNIMESH_STATUS_TOKEN.
  3. Lost that folder too? In Cloudflare go to Workers & Pages → your app (its name starts with om-) → Settings → Variables and Secrets → Add. Choose type Secret, name OMNIMESH_STATUS_TOKEN, paste a new random value of at least 32 characters, and press Deploy. Then sign in here with that value.
